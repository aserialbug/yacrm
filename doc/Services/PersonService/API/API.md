# API - PersonService OpenAPI Specification

## Описание

Публичное REST API сервиса PersonService для управления сущностью Person.

Согласно ADR 001, описание API ведётся в виде YAML файлов с контрактами OpenAPI 3.1.0.

## Версии

| Версия | Статус | Описание |
|--------|--------|----------|
| 1.0.0 | Разрабатывается | Первоначальная версия CRUD операций |
