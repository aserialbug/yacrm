# Требования к PersonService

Сервис PersonService обрабатывает информацию о людях. Сервис хранит информацию в БД

Основной агрегат Person имеет следующие поля:

|            |              |             |                                                       |                               |
| ---------- | ------------ | ----------- | ----------------------------------------------------- | ----------------------------- |
| Название   | Обязательное | Базовый тип | Ограничения                                           | Комментарии                   |
| FirstName  | Да           | Строка      | Макс. длинна 50                                       | Имя                           |
| MiddleName | Нет          | Строка      | Макс. длинна 50                                       | Отчество                      |
| LastName   | Да           | Строка      | Макс. длинна 50                                       | Фамилия                       |
| SocialLink | Нет          | Строка      | Макс. длинна 255                                      | Ссылка на профиль в соц сетях |
| Email      | Нет          | Строка      | Мин. длинна 5, макс длинна 25                         | Email пользователя            |
| Phone      | Да           | Строка      | Мин. длинна 5, макс длинна 12, состоит только из цифр | Сотовый телефон               |

Сревис должне реализоывать REST API основных CRUD опреаций над сущностью Person.
