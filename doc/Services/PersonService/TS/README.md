# TS - Technical Solutions для PersonService

## Описание

Технические решения содержат конкретные списки изменений кода для реализации требований к продукту (PR).

Согласно ADR 001, каждый файл TS имеет номер, соответствующий номеру PR.

## Файлы

| Файл | Соответствует PR | Описание |
|------|------------------|----------|
| [TS 001 Person entity.md](TS%20001%20Person%20entity.md) | PR 001 | Реализация сущности Person |

## Структура TS документа

Каждый файл TS содержит:

1. **Статус** — текущее состояние решения
2. **Ссылки** — на связанные PR, CD, PDM, API документы
3. **Архитектура проекта** — структура папок и файлов
4. **Задачи реализации** — пошаговые инструкции с кодом:
   - Доменный слой
   - Прикладной слой
   - Инфраструктурный слой
5. **Скрипты миграции БД**
6. **Проверка реализации**
