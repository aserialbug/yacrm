# ADR 004 Модель предметной области

## Статус

Разрабатывается

## Контекст

Необходимо зафиксировать подходы используемые при проектировании модели предметной области

## Решение

В модели предметной области есть два типа объектов:

1. Сущности. Объекты уникально идентифицируемые по своему идентификатору и поддерживающие обновление значений своих атрибутов в течении жизни. Все классы сущностей являются производными от базового класса сущности. Каждая сущность содержит идентификатор, который моделируется объектом-значением.

2. Объекты-значения. это неизменяемые объекты, которые описывают характеристики или свойства сущностей, но не имеют собственного уникального идентификатора. Их равенство определяется исключительно их содержимым. Для простых атрибутов модели должны создаваться отдельные объекты-значения. Объекты-значения должны иметь приватный конструкор и фабричный метод для создания их экземпляров. Объектоы-значения инкапсулируют логику валидации значений которые они представляют

В модели предметной области не должно быть одержимости примитивами

## Последствия

Фиксирование подходов позволяет писать понятный код которй легко поддерживать
