# ADR 004 Модель предметной области

## Статус

Разрабатывается

## Контекст

Необходимо зафиксировать подходы используемые при проектировании модели предметной области

## Решение

В модели предметной области есть два типа объектов:

1. Сущности. Объекты уникально идентифицируемые по своему идентификатору и поддерживающие обновление значений своих атрибутов в течении жизни. Все классы сущностей являются производными от базового класса сущности

2. Объекты-значения. Не имеют своего идентификатора и определяются своим состоянием. Объекты значения неизменяемы. Поддерживают изменения только посредством копирования. Объекты-значения инкапсулирующие единственный атрибут не должны содержать его публичного геттера, должны содержать приватный конструктор и фабричные методы для создания объектов этого типа.

Модель предметной области по возможности не должна содержать атрибуты скалярных типов. Все типы атрибутов модели должны оборачитваться в объекты значения, которые инкапсулируют скалярный тип и реализуют логику валидации значений.

В модели предметной области не должно быть одержимости примитивами

## Последствия

Фиксирование подходов позволяет писать понятный код которй легко поддерживать
