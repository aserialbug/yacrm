# ADR 003 Технологии в проекте

## Статус

Разрабатывается

## Контекст

Необходимо зафиксировать список технологий, которые будут использованы при реализации проекта.

## Решение

* Сервисы проекта реализуются на языке C# на платформе .net core 10.

* Основная БД используемая на проекте это PostgreSQL версии 18

* Фронтенд решения создается с помощью Vue.js

* Разворачиваться решение будет с помощью Docker Compose

## Последствия

Закрепление технологического стека позволит минимизировать количество использованных технологий и упрстить поддержку и развертыванеи проекта.
